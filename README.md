# cpp00

Module 00 of the C++ Piscine at 42 Paris.

## Description

This repository contains exercises and practice code for the first module of the C++ Piscine (42). The exercises focus on basic C++ syntax, compilation, and small programs to build familiarity with the language and tools.

## Requirements

- A C++ compiler supporting C++ (g++, clang++)
- make (if a Makefile is present)

## Build

If the repository contains a Makefile, build with:

```bash
make
```

If no Makefile is present, compile individual files with:

```bash
g++ -Wall -Wextra -Werror -std=c++98 -o program file.cpp
```

## Usage

Run compiled programs produced by the Makefile or compilation commands above. Specific usage depends on each exercise; check source files for details.

## Project structure

- src/ or individual .cpp files — exercise implementations
- includes/ or headers — header files (if present)
- Makefile — (optional) build rules
